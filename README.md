# Rock-papers-Scissors
## Rock Paper Scissors (Java + Swing)

A simple Rock-Paper-Scissors game built using Java.
The game runs in the console and displays the final score using a Swing GUI.

## Features
Play Rock, Paper, Scissors against the computer
Randomized computer moves
Score tracking (Player vs Computer)
Final result displayed in a GUI window
Clean and simple UI using Swing
🛠️ Technologies Used
Java
Swing (for GUI)
IntelliJ IDEA
## How to Run

Clone the repository:

git clone <your-repo-link>
Open the project in IntelliJ (or any Java IDE)

Run the main file:

Game.java
## How to Play
Enter your choice:
rock
paper
scissors
The computer will randomly choose its move
The winner of each round is decided
At the end, a GUI window displays:
Player score
Computer score
Final result (Win/Lose/Tie)
## Concepts Used
Java Classes & Objects
Conditionals (if-else)
Loops
Scanner for input
Random for computer moves
Swing (JFrame, JLabel) for UI
